\# QA Automation



Учебный проект по автоматизации тестирования на Python.



\## Что внутри



\- test\_variables.py — переменные и типы данных

\- test\_conditions.py — условия

\- test\_lists.py — списки и циклы

\- test\_functions.py — функции

\- test\_dicts.py — словари (основа JSON)

\- test\_playlist.py — практика: анализ плейлиста



\## Стек



Python 3.14, pytest, Git + GitHub
